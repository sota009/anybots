Anybots · 提案 · 2026-10-04

到達を、最速で1回だけ届ける。

Composio が行動、Supermemory が記憶を取ったあとに残る層は、自分が運営していないエージェントへ依頼を届けること。街や役所にエージェントがいる世界は、その層が不可逆だと示す物語。ローンチそのものは、その物語より狭い。

この文書は提案であり、実装済みの仕様ではない。現行の製品は README、docs/architecture.md、運営手順が正。数字は各社発表と二次記事が混在するので、出典節で信頼度を分けてある。

判定

残す カテゴリは到達。動詞は ask。供給は自分で置く。
削る 自治体営業、課金、標準化、リレーのOSS化は初回出荷に入れない。
出荷の定義 見知らぬ人が SSH なしで公開エージェントへ1回聞き、返事が画面に残る。

すでに証明できているのは、運営が結んだ dots と Grok の実アカウント往復（2026-10-03）と、実行中の Muse と Grok の往復（2026-10-04）。これはエンジンの証拠。公開製品の証拠にはまだなっていない。初回接続の記録では、Grok の通常チャットにやり取りが出なかった。画面に残らない成功は、ローンチでは成功に数えない。

取る層

人間がアプリと窓口のあいだを運ぶのが、戻ると壊れる変化。自分のエージェントは自分の道具と記憶まで届く。店、窓口、街頭は、それぞれの画面のまま残っている。次の相手を足すときに、また人間が貼り付け役に戻るのが損になったとき、この層は標準になる。

記憶 · 埋まっている

到達 · ここ

Anybots

自分が運営していないエージェントへ、範囲つきで聞いて、返事を受け取る。

発見の住所は AID の DNS に乗せる。会話の封筒を新しく作って A2A と並ばない。ツール実行を取りにいって Composio と並ばない。Anybots が運営するのは、その先の同意、起床、完了の記録。

事例から盗む型

Browser Use を中心に、インフラとして先に広がった製品の共通点は「名詞が1つ、見知らぬ人が数分で結果を見る、ホスト課金は自分で運用する苦痛に後から付く」。評価額は売上より先に動く。売上の前に物語を出してよいが、動く1呼び出しより先に物語を出すと嘘になる。

Browser Use

オープンコア → 使った分だけ

週末の実験を Hacker News に出した、と創業者自身が書いている。ライブラリが先に広がり、資金調達の投稿時点で GitHub 星 50,000、開発者 15,000 以上。2025-03-23、TechCrunch が Felicis 主導のシード 1,700 万ドルを報じた。YC のクラウド発表では、OpenAI Operator の4日後にホスト版を出した、と自分たちで書いている。理由は、プロキシ、ログイン維持、並列実行を自分で抱えたくない利用者の要望。

現在の価格はサブスクリプションを置かず、5ドルからクレジット、期限なし。ブラウザ時間と通信、モデル代の20%を足す。登録者に15ドル分の無料クレジット。GetLatka の2025年ARR推計は140万ドルで、調達額より小さい。星は配布、請求はホストの苦痛、という分離が本体。

盗む。 見知らぬ人が今日試せる1動詞。ホストするのは「相手のエージェントを起こして記録する」misery。ライブラリをばらまいて星を稼ぐこと自体は真似しない。同意ネットワークは相手がいないと価値がゼロで、Browser Use のライブラリとはそこが違う。

Browserbase / Stagehand

SDKは無料、ブラウザは有料

2024年1月創業。2025年6月の Series B は Notable Capital 主導で4,000万ドル、評価額3億ドル、累計6,750万ドル、という二次報道がある。GetLatka 系の2025年ARRは440万ドル。Stagehand は act / extract / observe の3語で広がり、2026年8月に npm 月間578万ダウンロードというまとめがある。価格は無料、Developer 20ドル、Startup 99ドル、その後は時間と回数。

検索、取得、エージェント身元、モデルゲートウェイへ広げたのは、ブラウザという名詞が先に立ったあと。名詞を増やすのは配布のあと。

盗む。 開発者が貼る入口と、信頼性に課金するホストを分ける。最初の名詞がデフォルトになる前に製品面を増やさない。

Composio

開発者が先、監査が企業の理由

Together と Lightspeed の発表では、シード400万ドルのあとに Series A 2,500万ドル、累計2,900万ドル。その時点で開発者10万以上、企業200社以上、売上が7桁。2026年の同社資料では月間ツール呼び出し3億回以上、SOC 2 と ISO 27001、導入事例では自前 OAuth の約380時間を置き換えたと書いている。

盗む。 企業が買う文章は「新しい世界」ではなく「この時間を自分で書かなくてよい」と「依頼の前に範囲が効き、記録が残る」。到達の企業向け証拠は、相手ごとに接続を書かずに済んだ時間と、誰が何を聞いたかの記録。

Supermemory

触れる遊び場が、インフラの買い手を連れてくる

消費者向けのセカンドブレインから始まり、利用者5万、GitHub 星1万を自社ブログが記載。その運用の中で記憶の基盤が無いと気づき、API を売った。顧客に Composio、Cluely、Scira が入る。資金は同社ブログが300万ドル、TechCrunch（2025-10-06）が260万ドル。

盗む。 最初に触れるのは API 仕様書ではなく、今聞ける公開エージェント。API はその同じ受信箱。消費者アプリを別に作らない。

Firecrawl

退屈で難しい1呼び出し

URL を渡すと、エージェントが読める文章が返る。YC の求人は、1年目に ARR 8桁、2年目にその倍以上、GitHub 星17万以上、と自己申告している。2026年の同社ブログは Smash Capital 主導の Series B 7,500万ドル。無料クレジットのあと、ページと検索の回数で課金。後から Alexandria で複数の情報源を同じ API に足している。1呼び出しがデフォルトになったあとの拡張。

盗む。 ask(住所, 範囲, 依頼) を、URL を渡すのと同じ短さにする。複数の相手は、その1語の引数が増えるだけ。

Resend

最初の客は知人。10ドルで本気か確かめた

同社の沿革では、2022年9月に動く MVP を知人のスタートアップが本番で使い、10ドルの支払いリンクで本気かを見た。React Email が配布の入口。2023年1月の公開から約半年で開発者1万、送信700万通（TechCrunch、2023-07）。2023年12月に有料顧客1,000。2024年4月に利用者10万。2024年12月に Series A 1,800万ドル。2025年に利用者100万、2026年6月に300万。創業者は SendGrid の次ではなく Twilio の次と言いながら、メールという名詞から動かなかった。

盗む。 出荷の定義を満たしたあと、知人1人に少額を払ってもらう。Stripe を先に作らない。名詞を増やすローンチウィークは、最初の ask が外で成功してから。

戦略への批判

前回までの「到達層、街にエージェントが宿る、人間が運搬係をやめる」は方向として維持する。それを初回ローンチの作業リストにすると、Browser Use がやらなかった失敗を自分から選ぶことになる。

維持する 認証から送信者を決める。通知に本文を載せない。相手の文章を許可や購入にしない。結果不明を自動再送しない。dots、Grok、Muse の資格情報を混ぜない。この5つは、標準になったあとに必要になる性質で、すでに試作の中心にある。作り直さない。
初回出荷から外す 実在の自治体との接続。利用者同士の友達追加。グループ調整。Poke。音声。ファイル。決済。A2A 互換。リレー本体のオープンソース化。接続一覧 CLI の一般公開。課金システム。Muse をデモの主役にすること。Grok 発の新規会話は未検証のまま、デモの開始側は動いた経路に固定する。
読み替える 「標準になる」は結果であって、ローンチの宣言ではない。2人目が同じ住所を叩き、3人目が自分のエージェントをその住所帳に載せたとき、標準の最初の証拠になる。それまでは参照実装。白井市の2026年4月の案内アバターは、来庁者がその場で話す画面の実例であり、外部から呼べる API が存在する証拠ではない。物語の比喩に使い、接続先の合意として扱わない。
この戦略が簡単に死ぬ場所 デモが「自分たちのボット同士の雑談」だと、到達の証拠にならない。個人のエージェントから、別の運営主体の公開エージェントへ聞けることが最低条件。公開エージェントの中身は自前でよい。聞く側が自前の運営手順だと、見知らぬ人の出荷にはならない。もう一つの死に方は、中継は成功して画面が無言のまま投稿すること。2026-10-03 の記録がすでにその穴を見せている。

再設計した戦略

一文

自分のエージェントから、入れていないアプリの窓口へ、許可した範囲だけ聞いて、返事が今いる画面に戻る。

誰が最初の利用者か

すでに dot か Grok を持っていて、運営の知人ではない1人。この人は市役所の職員でも、新しいアプリの登録者でもない。持っているエージェントに1文を貼る人。

誰が最初の相手か

自分たちでホストする2つの公開エージェント。案内窓口は「どの手続きの話か」に定型で答え、証明書は発行しない。角の店は「残っているか」に定型で答え、注文は受けない。副作用が無いので、バックアップと保存期限が未了の本番に、他人の私的な会話を載せずに公開できる。

冷たいスタートの扱い

最初は需要も供給も自分たちに見える。それは Browserbase がブラウザを自分で用意し、Composio がコネクタを自分で用意したのと同じ。次の関門だけがネットワークの証拠で、外部の誰かが3体目の住所を自分で公開できること。ローンチの完了条件には入れず、ローンチの次の関門として固定する。

ハイプの単位

図は、行動・記憶・到達の3マス。動画は60秒で、見知らぬ人のエージェントが案内窓口に聞き、ローンチページに返事が出るところまで。README もセキュリティモデルも投稿しない。英語の開発者向けには同じ動詞を併記する。日本語の比喩は白井の窓口でよいが、製品のプロンプトは住所と範囲が読めれば言語を選ばない。

ビジネスモデル

課金対象はアイデアではなく、自分で持ちたくない運用。起床、相手ごとの接続、範囲の検査、監査の保存、検証済みの公開住所。本文の広告、会話の学習利用、関係グラフの販売は商品にしない。

PHASE 0 · ローンチ

無料、上限、売上ゼロ

サンドボックスだけ。接続ごとの1日の完了回数を小さく固定する。目標は運営以外の完了した ask が20件。全体共通の実験上限（1日200通知）のまま投稿すると、当たった日に黙る。投稿の前にサンドボックスの枠を分離する。

PHASE 1 · 動いたあと

完了した ask のクレジット

Browser Use と同じく席課金にしない。期限のない少額チャージ。起床に失敗した試行は請求しない。Resend に倣い、最初の外部成功のあと知人1人へ少額の支払いを依頼し、本気かを見る。その支払いリンクのために請求基盤を先に作らない。

PHASE 2 · 場所が客になる

検証済み住所の月額

店と窓口が、自分のエージェント住所、監査の書き出し、到達の保証を買う。電話番号を買うのに近い。自治体はここの顧客。公開サンドボックスが何百回も聞かれたあとに売る。

PHASE 3 · 統制

記録と権限の分離

Composio が SOC 2 のあとに売ったもの。範囲がモデルの前に効くこと、保存期間、組織の管理主体。バックアップ復旧、DB 権限分離、保存期限が証拠になってから。今のセキュリティ資料が公開拡大の前提にしている項目そのもの。

最速MVP

新しいプロトコルは作らない。今の受信箱の上に、見知らぬ人が通れるドアを1枚足す。

中身
動詞ask(住所, 範囲, 依頼)。中では既存の会話開始と受信完了を使ってよい。利用者が見る名前は ask だけ。
住所desk.demo と shop.demo。名刺に、場所、答える範囲、しないことを書く。
入口1つの URL。ブラウザで一度きりの接続。接続コードを AI との会話へ貼らせない。貼る依頼文は1つ。
表示ローンチページに、依頼、返事、時刻が残る。本人の通常チャットに残ることも同時に直す。ページ側が欠けたら投稿しない。
境界パイロット所有者の本番の許可とは別のサンドボックス。回答は定型で、外部の副作用が無い。私的な受信箱をこの公開面に混ぜない。
上限接続ごとの完了回数。使い切りは黙って落ちず、理由を返す。

完了したと呼ぶ条件

  1. 運営ではない人が、ドキュメントの運営手順を読まずに URL を開く。
  2. 持っている dot または Grok に、書かれた1文を貼る。
  3. 案内窓口が範囲内の問いに答え、ローンチページにその返事が出る。
  4. 途中で運営が SSH、秘密ファイル、Webhook 鍵を触っていない。
  5. 別の2人目が、同じ住所へ同じ手順で聞ける。

この5つが揃った動画が、最初の公開物。星の数、資金、自治体の関心は、この5つの代わりにならない。

実装の順番

開発方針どおり、各段は資料、失敗するテスト、最小実装の順。カレンダーの週では切らない。

  1. この戦略を提案として固定する。現行仕様の文書は、実装が終わるまで書き換えない。
  2. サンドボックスの境界を資料に書き、本番の許可や通知枠と混ざらないテストを先に落とす。
  3. 2体の公開エージェントと名刺。範囲外の依頼は実行せず拒否するテストを先に書く。
  4. サンドボックス限定の自己接続。既存の一度きりのブラウザ接続を、運営の SSH なしでこの相手だけに使えるようにする。
  5. ローンチページに、そのサンドボックスの受付記録だけを出す。本文の全会話ダンプにはしない。
  6. 運営以外の1人で完了条件を通し、操作回数と運営の介在を記録する。
  7. 2人目が同じ住所を叩けたら、60秒の動画を公開する。
  8. 外部の完了が20件に達してから、少額課金の実験を設計する。3人目が自分の住所を公開できることは、その次の関門。

中止条件

見知らぬ人が運営の手を借りないと終わらないなら、機能を足すのを止め、入口だけを直す。

返事がローンチページに残らないなら、投稿しない。

公開エージェントが範囲外の依頼を実行したら、公開を閉じる。定型回答の外へ賢くする作業より、拒否が先。

サンドボックスの枠が全体の実験上限と共通のままなら、宣伝しない。

パイロットの私的な会話を、この公開ページの材料に使わない。
