# Remote operator administration

`node scripts/remote-admin.mjs --config /absolute/connection.json --credentials-dir /absolute/private-directory` reads one existing admin JSON command from stdin. The JSON connection file must contain exactly `host` and `identityFile`; `identityFile` is an absolute path to a regular SSH private-key file. The pilot permits only `srv-db0lku9srm7s7384ral0@ssh.singapore.render.com`. Do not put credentials or pairing codes on the command line.

Register a dedicated SSH public key in Render and verify the Render SSH host key through a trusted channel before use. The wrapper never accepts a new or changed host key automatically. Render's current SSH setup instructions: https://render.com/docs/ssh (checked October 3, 2026).

The wrapper uses the system SSH client without a local shell, ignores SSH configuration files, disables forwarding, requires batch mode and the selected identity, and requires strict host-key checking. The remote operation is fixed to `cd /app && exec node dist/admin.js`. Input is limited to 16 KiB; output, error streams, connection time and total execution time are bounded. It executes an operation once and never retries it automatically.

Successful responses must match the requested action's known metadata schema exactly. Unexpected keys, extra output, malformed JSON, unexpected statuses, and oversized streams fail closed. Remote stdout/stderr and exception messages are never printed. Ordinary output contains only validated metadata. `provision` and `connect` additionally retrieve the generated credential file using SSH and save it locally; their stdout contains a local credential-file path, never credential content.

Credential retrieval permits only `/app/.local/<UUID>.json` for provision and `/app/.local/<UUID>-connect-<UUID>.json` for connect, bound to the returned binding ID. Retrieval uses a fixed `cat` command plus this validated path. The destination directory and every parent component must not be symbolic links; the final directory must be owned by the current user and have mode 0700. Missing directories are created privately. Existing files are never overwritten; new credential files use exclusive creation and mode 0600. On systems where a system directory is a symlink, supply the physical path instead. The local machine and its directory ancestors must be trusted against concurrent renaming by another process with the same local privileges.

If the remote operation fails or times out, its effect may already have happened: inspect state before issuing another command. If credentials cannot be retrieved or saved, the error explicitly requires reissue and contains no remote details. Do not blindly rerun provisioning: inspect the binding, disable/revoke stranded credentials as appropriate, and issue replacement credentials through the existing operator workflow. The wrapper does not delete remote credential files or automatically repeat an operation.

Mocked tests cover rejection boundaries, secret output/error handling, file permissions, and failure behavior. They do not establish real Render SSH access, deployed admin compatibility, or an end-to-end agent connection. Real-account verification remains a separate step.
